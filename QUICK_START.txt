THE TECHNICAL EXPLANATION:

  BEFORE:
    • USB composite_with_iads = true → 1,000-2,000 interrupts/sec
    • I2C @ 100 kHz → 10 microsecond clock period
    • Result: USB interrupts delay I2C timing → Display breaks ✗

  AFTER:
    • USB composite_with_iads = true → 1,000-2,000 interrupts/sec
    • I2C @ 400 kHz → 2.5 microsecond clock period (4x faster)
    • Result: I2C completes between USB interrupts → Both work ✓

WHAT CHANGED IN CODE:

  File: src/bin/main.rs
  Lines: 196-204

  OLD:
    let i2c = I2c::new(peripherals.I2C0, I2cConfig::default())

  NEW:
    let i2c = I2c::new(
        peripherals.I2C0,
        I2cConfig::default()
            .with_frequency(Rate::from_khz(400))
    )
