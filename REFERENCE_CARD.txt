┌─ PACKET FORMAT ─────────────────────────────────────────────────────────────┐
│                                                                              │
│  One command = 16 bytes (little-endian):                                   │
│    Bytes 0-3:   Index    (u32)                                              │
│    Bytes 4-7:   Value    (u32)                                              │
│    Bytes 8-15:  Delay_ms (u64)                                              │
│                                                                              │
│  Example in Python:                                                         │
│    struct.pack('<IIQQ', 0, 1300, 0)  # Button A, immediate                │
│                                                                              │
│  Limitations:                                                                │
│    • Max queued: 256 commands                                               │
│    • Max delay: 36,000,000 ms (~10 hours)                                  │
│    • Max value: 4,294,967,295 (u32)                                         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

│                                                                              │
